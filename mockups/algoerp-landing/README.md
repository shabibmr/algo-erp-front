# algoERP — Today’s Desk (dashboard mockup)

Light-theme ERP dashboard mockup aligned with **Ledger & Linen**.

| Axis | Choice |
|------|--------|
| Vibe | Editorial Luxury (linen / paper / lagoon) |
| Layout | Asymmetrical Bento + soft Z-axis sticky notes |
| Content | Greeting · Needs you · Continue · Quiet pulse · Chart · Top customers · Ledger sheet |

## Open

```bash
start mockups/algoerp-landing/index.html
```

Or:

```bash
npx --yes serve mockups/algoerp-landing
```

## Files

- `index.html` — shell + dashboard content  
- `styles.css` — tokens, bento, motion  
- `script.js` — menu, reveals, magnetic CTAs, toast
