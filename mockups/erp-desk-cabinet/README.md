# algoERP — Chrome-free desk (Cabinet + Spotlight)

Recipe **L**: Mac Launchpad-style module grid + Spotlight. No sidebar, no top navbar.

| Path | Role |
|------|------|
| `index.html` | Full-bleed Today’s Desk |
| `styles.css` | Ledger & Linen light + overlays |
| `script.js` | Cabinet, Spotlight, keyboard |

## Open

```bash
start mockups/erp-desk-cabinet/index.html
```

## Interact

| Action | Result |
|--------|--------|
| Floating **Cabinet** seal | Launchpad grid |
| **⌘K** / **Ctrl+K** | Spotlight |
| **⌘.** / **Ctrl+.** | Toggle Cabinet |
| **Esc** | Close overlays |
| Filter / folders | Narrow modules |

Original nav-chrome mockup remains at `mockups/algoerp-landing/`.
